# DS&A — Lower Bounds and Impossibility Proofs

## About the course

This repository is part of my coursework for **Data Structures and Algorithms**, a university course on algorithm analysis and design. Topics include asymptotic analysis, sorting, balanced search trees, hashing, graphs and shortest-path algorithms, dynamic programming, and amortized analysis — with both written theoretical exercises and a final programming project.

## About this assignment

This exercise is about proving that certain combinations of operations are *impossible* to support within given time bounds, using comparison-based lower bounds. A representative question asks to show that no general-purpose data structure — relying only on key comparisons — can simultaneously support `insert` in `O(√log n)`, `delete` / `search` in `O(log n)`, and `extract-min` in `O(√log n)`. Each answer sets up the comparison-tree / information-theoretic argument and derives the contradiction.
